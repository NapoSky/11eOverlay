11eOverlay

Overlay de jeu transparent pour Foxhole, intégré à l'API ArtyCon.
Groupes d'artillerie, batteries, cibles et solutions de tir en temps réel.

Télécharger pour Windows Contribuez sur GitHub

Windows x86_64 · Dernière version stable

Fonctionnalités

  • Overlay transparent par-dessus le jeu, toujours au premier plan.
  • Mode Lexique — sigles et jargon Foxhole (armes, véhicules, structures, radio) consultables sans quitter le jeu.
  • Mode Artillerie — groupes, batteries, cibles et solutions de tir (azimut, distance) synchronisés en temps réel via ArtyCon.
  • Connexion Discord ou login local pour s'authentifier.
  • Raccourcis clavier configurables pour afficher ou masquer l'overlay.
  • Léger — fonctionne en arrière-plan sans impacter les performances.

Installation

  1. Téléchargez le zip ci-dessus.
  2. Extrayez 11eOverlay.exe où vous le souhaitez.
  3. Lancez l'exécutable et authentifiez-vous.
